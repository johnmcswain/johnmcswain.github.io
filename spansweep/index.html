Instrumentation · Experimental Design

Every measurement tool is an experiment. The question is which variable it sweeps.

Hold everything else fixed, vary one factor, watch the curve. k6, Artificial Analysis, and SpanSweep all follow that formula; they just pin different terms. Select an instrument to see its experimental design.

    The composition layer, concretely

    Four public-domain composition patterns, the kind of "Architecture" values SpanSweep sweeps. Same task, same models; only the arrangement changes. Node color: worker · orchestration.

    misroute rate and escalation cost, with model assignment as a second swept variable

    Structural conformance: declared vs. realized

    An experiment has an expected structure; telemetry does not. Because SpanSweep declares the topology ex ante and reconstructs the realized structure from span parentage, the gap between the two is itself measurable. Illustrative run below: a declared 3-way fan-out, and what actually executed.
