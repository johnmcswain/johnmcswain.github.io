# John McSwain's PWA

This is a static progressive web app (PWA) hosted on GitHub Pages.

## Features
- **Responsive Design**: Adapts to different screen sizes.
- **PWA Capabilities**: Installable and works offline via Service Worker.
- **Custom Styling**: Dark theme with specific Google Fonts.

## Setup

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/johnmcswain/johnmcswain.github.io.git
    cd johnmcswain.github.io
    ```

2.  **Start the local server**:
    You can use Node.js to start a local development server.
    ```bash
    npm start
    ```
    This command uses `npx http-server` to serve the files.

3.  **View the site**:
    Open your browser to the URL shown in the terminal (usually `http://127.0.0.1:8080`).
